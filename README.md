### 1. The Sahyadri Legacy

**[Explore the Research](./The-Sahyadri-Legacy/)**

### 2. KrishiSahayak

**Topic:** Predicting Agricultural Distress Risk Across Maharashtra Districts

A machine-learning research project exploring the classification of agricultural distress risk into Low, Medium, and High categories using rainfall, temperature, sown area, and historical crop-yield patterns.

The project compares Logistic Regression and XGBoost and explores the potential of early-warning systems to support agricultural planning.

**Topics covered:** Machine learning, predictive modelling, agricultural analytics, feature engineering, model validation, and data visualization.

**[Explore the Research](./KrishiSahayak/)**
